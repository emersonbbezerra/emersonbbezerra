## Sobre mim

Sou desenvolvedor de software com foco em backend, APIs REST e arquitetura de sistemas.

Minha trajetória profissional combina pensamento analítico, resolução de problemas e desenvolvimento de produtos digitais. Atualmente trabalho na construção de aplicações modernas utilizando TypeScript, Node.js, React, bancos de dados relacionais e práticas de engenharia de software.

Também venho expandindo minha atuação com Java, Spring, AWS, Docker, Cloud e Inteligência Artificial.

Acredito que tecnologia gera valor quando resolve problemas concretos, melhora processos e cria experiências mais simples para as pessoas.

## Projetos atuais

### [BakeCost](https://github.com/emersonbbezerra/bake-cost)

Plataforma completa para gestão e precificação de confeitarias, com recursos para cálculo de custos, receitas, insumos, pedidos e organização financeira.

O projeto envolve:

- React e TypeScript
- Fastify e Prisma
- PostgreSQL
- Autenticação e multi-tenancy
- Docker
- Testes unitários, integração e E2E
- Arquitetura modular
- Regras de negócio financeiras

### [Mapi Vision Suite](https://github.com/emersonbbezerra/mapi-vision-suite)

Projeto voltado à aplicação de visão computacional e Inteligência Artificial em cenários de cidades inteligentes, transformando dados visuais em informações úteis para análise e tomada de decisão.

Atuação envolvendo desenvolvimento de software, integração de serviços, deploy e evolução contínua de produtos digitais.

### [draft.occa](https://github.com/emersonbbezerra/draft.occa)

Projeto desenvolvido no ecossistema [occa.dev](https://occa.dev), explorando a criação de produtos digitais modernos com foco em interfaces, experiência do usuário e soluções web orientadas a problemas reais.

O projeto representa meu trabalho com desenvolvimento colaborativo, experimentação técnica e uso de tecnologias atuais para transformar ideias em produtos funcionais.
